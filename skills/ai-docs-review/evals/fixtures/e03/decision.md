# Решение о поставке каталога

Статус: принято владельцем продукта для MVP; заменяет [предыдущее решение](archive.md).

## Сценарий

Пользователь открывает каталог и просматривает текущие данные внешнего сервиса.
История и работа без сети исключены из MVP. Настройки пользователя не сохраняются.

## Поставка

Angular SPA на TypeScript поставляется статическими файлами.
Браузер обращается к внешнему API напрямую. Собственные серверные процессы,
постоянная копия каталога и база данных в этом этапе не создаются.

## Условия интеграции

В рамках учебного проекта поставщик подтверждает публичное чтение каталога без
секретов, CORS для адреса приложения и доступность операции из браузера.
Эти условия заданы входом; дополнительная проверка реального сервиса не требуется.

## Приёмка поставки

Статические файлы размещены на существующем хостинге.
При доступном API приложение отображает текущий каталог; при недоступности
показывает ошибку загрузки. Отдельные сервер приложения и БД для запуска не нужны.
