# План реализации каталога

Статус: актуальный план MVP после принятия [решения о поставке](decision.md).

## Порядок работ

1. Создать собственный сервер с HTTP-операцией выдачи каталога для SPA.
2. Подключить PostgreSQL и написать миграцию таблицы элементов каталога.
3. Добавить фоновую синхронизацию внешнего API в таблицу; читать список через сервер.
4. Реализовать список в Angular и сообщение об ошибке загрузки.
5. Разместить статические файлы на существующем хостинге.

## Готовность MVP

Сервер и PostgreSQL запущены, миграции применены, фоновая синхронизация завершена.
Браузер показывает каталог через собственный сервер; при отказе показывает ошибку.
