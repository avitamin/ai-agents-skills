# Локальный каталог

Статус: требования приняты владельцем продукта для первого этапа.
Цель: дать пользователю найти название в небольшом фиксированном списке.
Результат этапа — статическая HTML-страница с JavaScript, открываемая в браузере.

## Данные

Данные включаются в страницу; API, авторизация и внешние ресурсы не используются.
В этой версии список состоит из трёх записей в заданном порядке:

| id | title |
|---|---|
| 1 | Реестр услуг |
| 2 | Новости |
| 3 | Архив услуг |

## Поведение

При открытии страницы поле с видимой подписью «Поиск по названию» пусто, показаны
все три названия. После каждого изменения поля список пересчитывается синхронно.
Запрос очищается от пробелов по краям и приводится к нижнему регистру.
Название также приводится к нижнему регистру; запись показывается, если название
содержит запрос как подстроку. Порядок записей сохраняется, дубликаты не добавляются.
Пустой запрос показывает весь список. При отсутствии совпадений вместо списка
выводится «Ничего не найдено». Никаких запросов к сети при поиске нет.
После перезагрузки страницы поле снова пусто; сохранение запроса не требуется.
Редактирование данных, пагинация и нечёткий поиск вне первого этапа.

## Приёмка

Проверить в установленном браузере с поддержкой JavaScript:

| Действие / значение поля | Ожидаемый результат |
|---|---|
| Открыть страницу | Пустое поле; названия записей 1, 2, 3 |
| Ввести `услуг` | Названия записей 1, 3 в этом порядке |
| Заменить на `  НОВОСТИ  ` | Только название записи 2 |
| Заменить на `zzzz` | «Ничего не найдено», названий записей нет |
| Заменить на три пробела | Названия записей 1, 2, 3 |
| Очистить поле | Названия записей 1, 2, 3 |
| Ввести `архив`, затем перезагрузить | Пустое поле; названия записей 1, 2, 3 |
