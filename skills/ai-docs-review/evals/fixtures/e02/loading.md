# Загрузка каталога

Статус: спецификация реализации следующего этапа.
Используется существующее API Catalogue версии 1.0.0 из соседнего `openapi.yaml`.
Для этого учебного проекта файл содержит полный контракт используемой операции.

## Запрос

Клиент запрашивает `GET /v1/items`. Авторизация для чтения каталога не требуется.
При сетевой ошибке или ответе, отличном от 200, показать «Не удалось загрузить каталог».

## Обработка ответа

При ответе 200 разобрать JSON и получить список из свойства `response.items`.
Для каждого элемента показать `title`, использовать `id` как ключ строки.
Пустой список означает сообщение «Каталог пуст».

## Приёмка

Ответ 200 с двумя элементами даёт две строки в порядке ответа.
Ответ 200 с пустым списком даёт сообщение «Каталог пуст».
Сетевой отказ даёт сообщение об ошибке без строк каталога.
